# Автоматизация

OpenPencil позволяет работать с файлами дизайна как с данными. Все операции редактора — создание фигур, настройка заливок, управление auto layout и экспорт ресурсов — доступны также из терминала, AI agents и программного кода. Не нужно устанавливать plugins, получать API key или ждать предоставления доступа.

Интерфейс редактора и средства автоматизации используют один движок. Любое действие, которое можно выполнить в интерфейсе, можно выполнить и из script.

## Общая идея

OpenPencil — не только графический редактор, но и набор инструментов для создания собственных продуктов.

Его можно встроить в другое приложение, дополнить собственным интерфейсом и использовать для специализированных процессов редактирования. Поэтому приложение, CLI, AI tools, JSX renderer, MCP server и SDK работают поверх одного и того же движка редактора.

## AI chat

Встроенный assistant может использовать более 90 инструментов, охватывающих возможности редактора. Опишите задачу обычным языком, например: «добавь всем кнопкам тень 16 px», «создай компонент карточки с вариантом для тёмной темы» или «экспортируй все фреймы на этой странице в масштабе 2×».

[AI chat →](./ai-chat)

## Совместная работа

Несколько пользователей могут одновременно редактировать документ через peer-to-peer WebRTC. Сервер и учётная запись не нужны: отправьте другим участникам ссылку на комнату. OpenPencil покажет их указатели и позволит следовать за выбранным участником.

Состояние документа синхронизируется с помощью CRDT, поэтому изменения автоматически объединяются даже при нестабильном соединении.

[Совместная работа →](./collaboration)

## Vue SDK

Создавайте редакторы на базе OpenPencil с помощью того же Vue SDK, который используется в приложении. SDK предоставляет контекст редактора, подключение холста, состояние выделения, модели команд, composables для панелей свойств и headless components.

[Vue SDK →](./sdk/)

## JSX renderer

Описывайте интерфейс с помощью JSX — синтаксиса, уже знакомого LLM по React. Один вызов может создать дерево компонентов с фреймами, текстом, auto layout, заливками и обводками. Такое описание получается компактным, декларативным и удобным для сравнения версий.

Можно выполнить и обратное преобразование: экспортировать выделенные объекты в JSX с классами Tailwind, чтобы передать результат разработчикам или снова обработать его с помощью LLM.

[JSX renderer →](./jsx-renderer)

## CLI

Просматривайте, проверяйте, экспортируйте и анализируйте документы без запуска редактора. CLI позволяет получить список страниц, найти объекты, извлечь design tokens, обнаружить проблемы компоновки и доступности и выполнить экспорт в PNG. Для последующей обработки все команды поддерживают JSON output.

CLI также подключается по RPC к запущенному приложению для компьютера, поэтому редактором можно управлять из scripts прямо во время работы.

[Просмотр файлов](./cli/inspecting) · [Экспорт](./cli/exporting) · [Анализ](./cli/analyzing) · [Scripts](./cli/scripting)

## MCP server

Подключите Claude Code, Cursor, Windsurf или другой MCP client к OpenPencil. Сервер предоставляет 90 инструментов для чтения, создания и изменения дизайна — те же инструменты использует встроенный AI chat. Доступны transport через stdio и HTTP с поддержкой sessions.

[MCP server →](/programmable/mcp-server)

## Зачем нужен открытый инструмент

Figma — закрытая платформа. Её MCP server предоставляет только чтение, доступ браузера через CDP был закрыт в версии 126, а файлы хранятся в проприетарном формате на чужих серверах. Для разработки plugins нужен отдельный runtime с ограниченным API.

OpenPencil предлагает другой подход: открытый исходный код под лицензией MIT, локальное хранение данных и программный доступ ко всем операциям. Вы можете просматривать и преобразовывать свои файлы, обрабатывать их в CI или передавать LLM без дополнительного разрешения.
