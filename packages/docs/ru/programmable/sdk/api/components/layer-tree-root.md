# LayerTreeRoot

`LayerTreeRoot` предоставляет структуру дерева слоёв и подключает interactions, не задавая markup и оформление.

Используйте его, если приложению нужна переиспользуемая tree structure, но внешний вид оно определяет самостоятельно.
