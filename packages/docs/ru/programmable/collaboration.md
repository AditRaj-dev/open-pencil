# Совместная работа

Несколько пользователей могут одновременно редактировать один документ. Участники соединяются напрямую: центральный server не передаёт данные, а создавать учётную запись не требуется.

## Ссылка на комнату

1. Нажмите Share в правом верхнем углу.
2. Скопируйте созданную ссылку `app.openpencil.dev/share/<room-id>`.
3. Отправьте её другим участникам.

Присоединиться может любой человек со ссылкой. Комната остаётся активной, пока её страница открыта хотя бы у одного участника.

## Синхронизируемые данные

- **Документ:** фигуры, текст, свойства и layout обновляются сразу после каждого изменения.
- **Указатели:** видны положение указателя, имя и цвет каждого участника.
- **Выделение:** остальные участники видят выделенные вами объекты.

## Follow mode

Нажмите avatar участника на верхней панели, чтобы следовать за его viewport. Положение холста и масштаб будут повторять его экран. Нажмите avatar ещё раз, чтобы выйти из Follow mode.

## Как устроена синхронизация

Участники соединяются напрямую через WebRTC, поэтому данные документа передаются из одного browser в другой без центрального server. Состояние хранится в CRDT — conflict-free replicated data type. Благодаря этому одновременные изменения автоматически объединяются.

Комната сохраняется локально. После перезагрузки страницы вы снова войдёте в неё с прежним состоянием.

## Советы

- Совместная работа доступна в browser и desktop app.
- Room IDs создаются с помощью криптографически стойкого генератора. Войти могут только пользователи, получившие ссылку.
- После отключения участника его устаревший указатель автоматически удаляется.
