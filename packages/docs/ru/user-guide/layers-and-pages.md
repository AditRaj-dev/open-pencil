# Слои и страницы

Интерфейс редактора состоит из трёх основных областей: слои слева, холст в центре и свойства справа. Ширину боковых панелей можно изменить перетаскиванием разделителей.

## Слои

Левая панель показывает иерархию документа в виде дерева.

### Дерево объектов

Нажмите стрелку рядом с frame, group или component, чтобы показать или скрыть его дочерние объекты.

### Изменение порядка

Перетаскивайте слои в списке, чтобы изменить порядок наложения. Объекты, расположенные выше, отображаются поверх остальных.

### Видимость

Нажмите значок глаза рядом со слоем, чтобы скрыть или показать его. Скрытый объект остаётся в дереве слоёв.

### Переименование

Дважды нажмите имя слоя и введите новое. <kbd>Enter</kbd> или нажатие за пределами поля сохраняет имя, <kbd>Escape</kbd> отменяет изменение.

### Связь с выделением на холсте

При выборе слоя в списке выделяется соответствующий объект на холсте. Если выделить объект на холсте, OpenPencil выделит его и в дереве.

## Страницы

Панель страниц содержит все страницы документа.

- **Перейти на страницу:** нажмите её вкладку. OpenPencil восстановит сохранённое для этой страницы положение и масштаб холста.
- **Добавить страницу:** нажмите кнопку добавления.
- **Удалить страницу:** удалите текущую страницу.
- **Переименовать страницу:** дважды нажмите имя. <kbd>Enter</kbd>, <kbd>Escape</kbd> или нажатие за пределами поля завершает редактирование.

У каждой страницы собственные холст, положение видимой области и масштаб.

## Свойства

Справа расположены три вкладки.

### Design

Здесь находятся свойства выделенных объектов:

- **Внешний вид:** прозрачность, общий или независимый радиус углов и видимость;
- **Заливка:** сплошной цвет, линейный, radial, angular и diamond gradient, изображение и привязка к переменной;
- **Обводка:** цвет, толщина, cap, join и dash pattern;
- **Эффекты:** drop shadow, inner shadow, layer blur, background blur и foreground blur;
- **Текст:** font family, размер, weight и кнопки B/I/U/S;
- **Layout:** настройки [auto layout](./auto-layout) для подходящих frames;
- **Экспорт:** масштаб, формат и кнопка экспорта — подробнее в разделе [Экспорт](./exporting).

Если ничего не выделено, вкладка Design показывает свойства страницы, в том числе цвет фона холста.

### Code

На этой вкладке выделенный объект представлен как код с подсветкой синтаксиса, номерами строк и кнопкой копирования. Доступны два формата:

- **OpenPencil JSX:** дерево компонентов, совместимое с `renderJsx()` и пригодное для двустороннего преобразования;
- **Tailwind CSS v4:** HTML с utility classes, например `<div className="flex gap-4 p-3">`, который можно перенести в проект на React или Vue.

### AI

AI chat создаёт и изменяет объекты по запросу на обычном языке. Открыть или закрыть вкладку можно также сочетанием <kbd>⌘</kbd><kbd>J</kbd>. Поддерживаются разные AI models через OpenRouter.

| Действие | macOS | Windows / Linux |

## Интерфейс на небольшом экране

На телефонах и небольших экранах боковые панели заменяет выдвижная нижняя панель. Вкладки переключают разделы Layers, Properties, Design и Code. Toolbar превращается в компактную горизонтальную панель с выбором категории.

## Советы

- Ширина панелей сохраняется и восстанавливается после перезагрузки.
- Дерево слоёв помогает выбрать перекрытый объект, до которого трудно добраться на холсте.
- Дополнительные действия находятся в [контекстном меню](./context-menu).
- Сочетания клавиш для порядка наложения, видимости и блокировки описаны в разделе [Выделение и преобразование](./selection-and-manipulation).
