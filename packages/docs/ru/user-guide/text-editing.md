# Текст

OpenPencil позволяет создавать текстовые объекты и редактировать rich text непосредственно на холсте.

## Создание текста

Нажмите <kbd>T</kbd>, затем нажмите холст. Появится пустой текстовый объект с мигающим cursor — можно сразу начинать ввод.

## Редактирование на холсте

Дважды нажмите существующий текстовый объект. Синяя рамка показывает, что включён режим редактирования. Нажмите за пределами объекта, чтобы сохранить изменения и выйти.

Текст отображается самим canvas renderer; отдельного видимого input поверх холста нет.

## Перемещение cursor

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| На один символ влево или вправо | <kbd>←</kbd> / <kbd>→</kbd> | <kbd>←</kbd> / <kbd>→</kbd> |
| На строку вверх или вниз | <kbd>↑</kbd> / <kbd>↓</kbd> | <kbd>↑</kbd> / <kbd>↓</kbd> |
| На одно слово | <kbd>⌥</kbd><kbd>←</kbd> / <kbd>⌥</kbd><kbd>→</kbd> | <kbd>Ctrl</kbd> + <kbd>←</kbd> / <kbd>Ctrl</kbd> + <kbd>→</kbd> |
| В начало или конец строки | <kbd>⌘</kbd><kbd>←</kbd> / <kbd>⌘</kbd><kbd>→</kbd> | <kbd>Home</kbd> / <kbd>End</kbd> |

Удерживайте <kbd>Shift</kbd> вместе с клавишей движения, чтобы расширить text selection.

## Выделение текста

- Нажмите внутри текста, чтобы установить cursor.
- Нажмите и перетащите указатель, чтобы выделить диапазон.
- Дважды нажмите слово, чтобы выделить его.
- Трижды нажмите текст, чтобы выделить всё содержимое объекта.

## Rich text

Formatting применяется к выделенному диапазону. Если диапазон не выделен, кнопка меняет стиль всего текстового объекта.

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Bold | <kbd>⌘</kbd><kbd>B</kbd> | <kbd>Ctrl</kbd> + <kbd>B</kbd> |
| Italic | <kbd>⌘</kbd><kbd>I</kbd> | <kbd>Ctrl</kbd> + <kbd>I</kbd> |
| Underline | <kbd>⌘</kbd><kbd>U</kbd> | <kbd>Ctrl</kbd> + <kbd>U</kbd> |

Strikethrough включается кнопкой **S** в разделе Typography. Отдельного сочетания нет, поскольку <kbd>⌘</kbd><kbd>S</kbd> используется для Save.

Стиль хранится для каждого символа. Если вводить текст между bold и regular segments, новые символы наследуют стиль предыдущего segment.

Formatting также можно изменить кнопками **B / I / U / S** в разделе Typography.

## Редактирование

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Удалить предыдущее слово | <kbd>⌥</kbd><kbd>⌫</kbd> | <kbd>Ctrl</kbd> + <kbd>Backspace</kbd> |
| Удалить до начала строки | <kbd>⌘</kbd><kbd>⌫</kbd> | — |
| Cut | <kbd>⌘</kbd><kbd>X</kbd> | <kbd>Ctrl</kbd> + <kbd>X</kbd> |
| Copy | <kbd>⌘</kbd><kbd>C</kbd> | <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Paste | <kbd>⌘</kbd><kbd>V</kbd> | <kbd>Ctrl</kbd> + <kbd>V</kbd> |

## Font picker

Откройте Font picker в разделе Typography, чтобы выбрать font family.

- **Поиск:** сокращает список по мере ввода.
- **Preview:** имя каждого шрифта показано его собственным typeface.
- **Virtual scroll:** поддерживает большие каталоги без задержек.
- **Текущий font:** при открытии picker список прокручивается к выбранному family и выделяет его.

## Font weight

Доступные weights зависят от font family, например Regular, Medium, Bold и Black.

## Источники fonts

- **По умолчанию:** Inter загружается автоматически.
- **Desktop app:** системные fonts и включённые каталоги Google Fonts, Fontsource, Bunny Fonts и Fontshare.
- **Browser:** системные fonts доступны в Chrome и Edge; online font catalogs требуют desktop app.
- **Загруженные fonts:** desktop app сохраняет скачанные faces для повторного использования на этом компьютере.

## Отсутствующие fonts и замены

Если нужные family или style загрузить не удалось, OpenPencil показывает предупреждение над редактором и не выдаёт fallback rendering за точное отображение typography.

Раскройте предупреждение, чтобы увидеть затронутые faces и выбранные substitutes. Кнопка **Select layers** выделяет соответствующие текстовые объекты. После изменения сетевого доступа, разрешения на локальные fonts или settings providers нажмите **Retry fonts**.

Style может быть синтезирован из другого загруженного face того же family. Если отсутствует весь family, используется Inter, когда он доступен.

## Советы

- Список fonts загружается при запуске, поэтому picker открывается без задержки.
- Поддерживается ввод через IME для китайского, японского и корейского языков.
- Rich text сохраняется при открытии и записи `.fig`.
- Text overrides внутри component instances описаны в разделе [Компоненты](./components).
