# Экспорт и файлы

OpenPencil экспортирует отдельные объекты как изображения, SVG или самостоятельные документы `.fig`. Редактор открывает полные документы `.fig` и `.pen`.

## Экспорт изображений

Выделите объект и откройте раздел Export на панели свойств.

### Настройки

- **Scale:** 0,5×, 0,75×, 1×, 1,5×, 2×, 3× или 4×. Для SVG масштаб не показывается, поскольку vector graphics не зависят от разрешения.
- **Format:** PNG с прозрачным фоном, JPG с белым фоном, WEBP с прозрачным фоном, SVG или отдельный документ `.fig`.

Для одного объекта можно добавить несколько вариантов экспорта с разными форматами и масштабами. Preview на клетчатом фоне показывает будущий результат.

### Способы экспорта

| Способ | macOS | Windows / Linux |
|--------|-------|-----------------|
| Сочетание клавиш | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>E</kbd> |
| Контекстное меню | Нажать правой кнопкой <kbd>→</kbd> Export… | Нажать правой кнопкой <kbd>→</kbd> Export… |
| Панель свойств | Нажать Export | Нажать Export |

В приложении для компьютера путь выбирается в системном диалоге. В браузере файл загружается обычным способом.

## Copy/Paste as

Контекстное меню **Copy/Paste as** позволяет поместить выделение в clipboard в нескольких форматах:

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Copy as text | — | — |
| Copy as SVG | — | — |
| Copy as PNG | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>C</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Copy as JSX | — | — |

- **Copy as text** копирует видимый текст выделенных объектов.
- **Copy as SVG** копирует SVG markup, который можно вставить в редактор кода или Inkscape.
- **Copy as PNG** выполняет отрисовку в масштабе 2× и копирует изображение, готовое для вставки в Slack, Notion и другие приложения.
- **Copy as JSX** копирует представление OpenPencil JSX, совместимое с `renderJsx()`.

## Документы .fig и .pen

OpenPencil использует тот же binary format `.fig`, что и Figma, а также открывает документы `.pen`.

### Открытие

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Открыть файл | <kbd>⌘</kbd><kbd>O</kbd> | <kbd>Ctrl</kbd> + <kbd>O</kbd> |

Диалог выбора показывает файлы `.fig` и `.pen`. В приложении для компьютера используется системный диалог.

### Сохранение

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Save | <kbd>⌘</kbd><kbd>S</kbd> | <kbd>Ctrl</kbd> + <kbd>S</kbd> |
| Save As | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>S</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>S</kbd> |

- **Save** перезаписывает текущий файл без дополнительного диалога.
- **Save As** позволяет выбрать новый путь.

Сохранённый файл сжимается и содержит thumbnail для показа в файловом менеджере.

### Совместимость с Figma

Файлы, экспортированные из OpenPencil, можно открыть в Figma, а документы Figma — в OpenPencil. Формат `.fig` сохраняет типы объектов, свойства, заливки, обводки, эффекты, vector data и параметры layout.

## Сочетания клавиш

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Экспортировать выделение | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>E</kbd> |
| Copy as PNG | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>C</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>C</kbd> |

| Save As | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>S</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>S</kbd> |

## Советы

- Для экранов с высокой плотностью пикселей используйте масштаб 2× или 3×.
- JPG всегда получает белый фон. Для прозрачности выберите PNG или WEBP.
- SVG подходит для последующего редактирования в Illustrator, Inkscape или коде.
- Thumbnail внутри `.fig` позволяет увидеть документ в файловом менеджере и диалоге открытия Figma.
