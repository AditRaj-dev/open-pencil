# Pen tool

Pen tool создаёт vector paths в формате vector network, совместимом с `.fig`.

## Включение

Нажмите <kbd>P</kbd>.

## Создание точек

- Нажмите один раз, чтобы поставить corner point и создать прямой segment.
- Нажмите и начните перетаскивание, чтобы поставить curve point с tangent handles Безье. Направление и расстояние перетаскивания задают форму кривой.
- Не отпуская кнопку мыши, удерживайте <kbd>Space</kbd>, чтобы переместить саму создаваемую точку.

Последовательно добавляйте точки, чтобы строить path segment за segment. Preview line соединяет последнюю точку с текущим положением указателя.

## Замкнутый path

Нажмите первую точку path, чтобы замкнуть его. Для замкнутого path можно использовать fill.

## Открытый path

Нажмите <kbd>Escape</kbd>, чтобы завершить path, не замыкая его. Открытые paths отображаются только со stroke и не получают fill.

## Vector networks

Вместо простого последовательного списка точек OpenPencil использует vector network. Такая модель поддерживает ветвления и сложную topology. Figma использует тот же подход, поэтому paths сохраняются при импорте и экспорте `.fig`.

## Сочетания клавиш

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Pen tool | <kbd>P</kbd> | <kbd>P</kbd> |
| Завершить открытый path | <kbd>Escape</kbd> | <kbd>Escape</kbd> |

## Советы

- Preview line всегда начинается в последней добавленной точке и не перескакивает в координаты `(0, 0)`.
- Чем дальше вы перетаскиваете указатель при создании curve point, тем длиннее tangent handles и шире изгиб.
- После создания path настройте fill, stroke и effects на панели свойств.
