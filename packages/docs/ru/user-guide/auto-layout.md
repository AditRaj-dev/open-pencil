# Auto layout

Auto layout автоматически размещает дочерние объекты внутри frame. Доступны два режима: **flex** с горизонтальным или вертикальным потоком и **grid** со строками, столбцами и настраиваемыми tracks.

## Включение Auto layout

- Выделите frame и нажмите <kbd>⇧</kbd><kbd>A</kbd>, чтобы включить или отключить Auto layout.
- Выделите объекты без общего родительского frame и нажмите <kbd>⇧</kbd><kbd>A</kbd>, чтобы поместить их в новый frame с Auto layout.

При создании frame объекты сортируются по положению: слева направо для горизонтального направления и сверху вниз для вертикального.

## Направление

- **Horizontal:** объекты располагаются слева направо.
- **Vertical:** объекты располагаются сверху вниз.
- **Wrap:** при нехватке места объекты переходят на следующую строку или в следующий столбец.

## Расстояния

### Gap

Расстояние между соседними дочерними объектами. Одно значение применяется ко всем промежуткам.

### Padding

Расстояние между границей frame и его содержимым. Можно задать общее значение или отдельные значения для верхней, правой, нижней и левой сторон.

## Выравнивание

### Justify — основная ось

Определяет распределение объектов вдоль выбранного направления:

- **Start:** у начала оси;
- **Center:** по центру;
- **End:** у конца оси;
- **Space between:** свободное место равномерно распределяется между объектами.

### Align — поперечная ось

Определяет положение объектов поперёк выбранного направления:

- **Start:** у начала поперечной оси;
- **Center:** по центру;
- **End:** у конца оси;
- **Stretch:** растянуть на всю доступную ширину или высоту.

## Размер дочерних объектов

Для каждой оси можно выбрать отдельный режим:

- **Fixed:** использовать явно заданную ширину или высоту;
- **Fill:** занять доступное место внутри parent;
- **Hug:** подобрать размер по содержимому.

## Изменение порядка

Перетащите дочерний объект внутри frame, чтобы изменить его место среди соседних объектов. Индикатор показывает будущую позицию.

## Панель свойств

Если выделен frame с Auto layout, раздел Layout содержит направление, gap, padding, justify и align.

## Сочетание клавиш

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Включить или отключить Auto layout | <kbd>⇧</kbd><kbd>A</kbd> | <kbd>Shift</kbd> + <kbd>A</kbd> |

## CSS Grid

Grid размещает дочерние объекты в строках и столбцах с явно заданными размерами tracks.

### Включение Grid

Выделите frame с Auto layout и нажмите значок grid в панели Layout, чтобы переключиться с flex на grid.

### Размеры tracks

Для строк и столбцов доступны три режима:

- **fr:** доля свободного места;
- **px:** фиксированный размер в пикселях;
- **auto:** размер по содержимому.

Например, `1fr 200px 1fr` создаёт три столбца: фиксированный центральный и два гибких боковых.

### Gap в Grid

Для строк и столбцов можно задать разные значения gap.

### Размещение объектов

По умолчанию объекты последовательно заполняют ячейки по строкам. В свойствах дочернего объекта можно изменить начальную строку или столбец и указать span.

### Экспорт в JSX и Tailwind

Grid экспортируется в JSX с классами Tailwind, например `grid grid-cols-3`, `gap-x-4 gap-y-2` и `col-start-2 row-span-2`.

## Советы

- После создания Auto layout вычисляется сразу, поэтому границы выделения обновляются без задержки.
- Вкладывайте frames с Auto layout друг в друга, чтобы создавать сложные адаптивные интерфейсы.
- Режим Fill соответствует применению оставшегося места, подобно `flex-grow: 1` в CSS.
- Grid подходит для dashboard, галерей, форм и другой двумерной структуры.
- Создание frames описано в разделе [Фигуры](./drawing-shapes).
- Использование Auto layout в переиспользуемых компонентах описано в разделе [Компоненты](./components).
