# CanvasSurface

`CanvasSurface` renderizza l’elemento `<canvas>` usato dal SDK renderer.

Dentro `CanvasRoot`, il SDK gestisce Refs e Renderer integration, mentre l’applicazione controlla Layout e Styles.
