# Navigazione nel canvas

Il canvas non ha limiti. Pan e Zoom consentono di raggiungere ogni area del documento.

## Pan

Sposta l’area visibile senza modificare gli oggetti:

- tieni premuto <kbd>Space</kbd> e trascina nel canvas;
- usa il Button centrale del Mouse;
- scorri con due dita sul Trackpad.

## Hand tool

Premi <kbd>H</kbd>. Finché Hand tool è attivo, qualsiasi Drag nel canvas sposta il Viewport senza tenere premuto <kbd>Space</kbd>.

Seleziona un altro Tool, per esempio Select con <kbd>V</kbd>, per uscire.

## Zoom

Zoom si centra sulla Position del Pointer:

- <kbd>Ctrl</kbd> + Scroll oppure <kbd>⌘</kbd> + Scroll su macOS;
- Pinch gesture sul Trackpad;
- scorciatoie della tabella.

Le Gestures sui pannelli Layers e Properties non vengono inviate al canvas. In questo modo non modificano né lo Zoom dell’editor né quello della pagina del Browser.

## Scorciatoie

| Azione | macOS | Windows / Linux |
|--------|-------|-----------------|
| Pan | <kbd>Space</kbd> + Drag | <kbd>Space</kbd> + Drag |
| Hand tool | <kbd>H</kbd> | <kbd>H</kbd> |
| Zoom in | <kbd>⌘</kbd><kbd>+</kbd> | <kbd>Ctrl</kbd><kbd>+</kbd> |
| Zoom out | <kbd>⌘</kbd><kbd>−</kbd> | <kbd>Ctrl</kbd><kbd>−</kbd> |
| 100% | <kbd>⌘</kbd><kbd>0</kbd> | <kbd>Ctrl</kbd><kbd>0</kbd> |
| Fit | <kbd>⌘</kbd><kbd>1</kbd> | <kbd>Ctrl</kbd><kbd>1</kbd> |
| Zoom to selection | <kbd>⌘</kbd><kbd>2</kbd> | <kbd>Ctrl</kbd><kbd>2</kbd> |

## Suggerimenti

- Posiziona il Pointer sull’area da mantenere al centro prima di usare Zoom.
- Hand tool rimane attivo finché non selezioni un altro Tool.
- Consulta [Selezionare e trasformare](./selection-and-manipulation) per modificare gli oggetti.
