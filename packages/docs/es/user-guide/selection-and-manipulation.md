# Seleccionar y transformar

Los objetos seleccionados se pueden mover, redimensionar, rotar, duplicar y cambiar de posición en el orden de Layers.

## Selection

- Click en un objeto sustituye la Selection actual.
- <kbd>Shift</kbd> + Click añade o elimina un objeto.
- Drag sobre una zona libre del canvas crea una Marquee selection y selecciona los objetos que intersecta.
- <kbd>⌘</kbd><kbd>A</kbd> selecciona todos los objetos de la Page actual.
- Click en una zona libre cancela la Selection.

## Mover

- Arrastra un objeto seleccionado.
- Arrow keys desplazan 1 px.
- <kbd>Shift</kbd> + Arrow keys desplazan 10 px.

## Resize

La Selection muestra ocho Handles: cuatro en las esquinas y cuatro en el centro de los lados. Arrastra uno para cambiar Width y Height.

Mantén <kbd>Shift</kbd> al arrastrar un Corner handle para conservar las proporciones.

## Rotation

Sitúa el Pointer justo fuera de un Corner handle hasta que aparezca el Rotation cursor y arrastra. Con <kbd>Shift</kbd>, la rotación se ajusta en pasos de 15°.

## Duplicate

- <kbd>⌥</kbd> o <kbd>Alt</kbd> durante el Drag crea una copia y la desplaza.
- <kbd>⌘</kbd><kbd>D</kbd> o <kbd>Ctrl</kbd><kbd>D</kbd> duplica en la misma posición.

## Delete

Backspace o Delete elimina todos los objetos seleccionados.

## Orden

- **]** lleva la Selection al frente.
- **[** la envía al fondo.

## Visibility y Lock

- <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> cambia Visibility.
- <kbd>⇧</kbd><kbd>⌘</kbd><kbd>L</kbd> cambia Lock.

## Atajos

| Acción | macOS | Windows / Linux |
|--------|-------|-----------------|
| Seleccionar todo | <kbd>⌘</kbd><kbd>A</kbd> | <kbd>Ctrl</kbd><kbd>A</kbd> |
| Duplicate | <kbd>⌘</kbd><kbd>D</kbd> | <kbd>Ctrl</kbd><kbd>D</kbd> |
| Duplicar y mover | <kbd>⌥</kbd> + Drag | <kbd>Alt</kbd> + Drag |
| Delete | <kbd>⌫</kbd>/<kbd>Supr</kbd> | Backspace/<kbd>Supr</kbd> |
| Mover 1 px | Arrow keys | Arrow keys |
| Mover 10 px | <kbd>⇧</kbd> + Arrow keys | <kbd>Shift</kbd> + Arrow keys |
| Llevar al frente | ] | ] |
| Enviar al fondo | [ | [ |
| Visibility | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> | <kbd>Shift</kbd><kbd>Ctrl</kbd><kbd>H</kbd> |
