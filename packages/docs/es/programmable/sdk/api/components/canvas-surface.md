# CanvasSurface

`CanvasSurface` renderiza el elemento `<canvas>` utilizado por el SDK renderer.

Dentro de `CanvasRoot`, el SDK gestiona las Refs y la Renderer integration, mientras la aplicación controla Layout y Styles.
