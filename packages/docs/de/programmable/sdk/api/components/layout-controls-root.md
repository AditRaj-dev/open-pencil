# LayoutControlsRoot

`LayoutControlsRoot` gibt das von `useLayout()` erzeugte API über seinen Slot weiter.

Die Anwendung kann damit ein eigenes Panel für Auto Layout und Sizing rendern, während State und Actions vom SDK kommen.
