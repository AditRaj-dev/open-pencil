    title: Programmierbar
    details: Headless CLI zum Untersuchen, Exportieren und Analysieren von .fig-Dateien. Figma Plugin API über eval, Tailwind-CSS-Export und JSON-Ausgabe für CI und Automatisierung.

    title: Toolkit statt nur einer App

    title: Integrierte KI
    details: Chat mit 90 Tools zum Erstellen von Formen, Ändern von Styles, Verwalten von Layouts und Analysieren von Tokens. MCP-Server für Claude Code, Cursor und Windsurf.
  - icon: 📖
    title: Open Source
    details: MIT-Lizenz. Editor, Engine, Dateicodec und CLI lassen sich vollständig einsehen und verändern.
  - icon: 🖥️
    title: Kostenlos und lokal
    details: Kein Konto, kein Server und keine Internetverbindung erforderlich. Desktop-App mit etwa 7 MB über Homebrew oder direkt als Web-App.
  - icon: 👥
    title: Zusammenarbeit in Echtzeit
    details: P2P über WebRTC ohne Server. Link teilen und gemeinsam mit Live-Cursors und Follow Mode bearbeiten.
